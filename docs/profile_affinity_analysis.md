# 用户画像信号分析与排序接入

## 结论

公开测试集中的 `preference_tags` 可以转化为稳定的商品排序信号，但它表达的是用户长期关注的商品方面，例如合身度、舒适度和耐用性，并没有给出某个具体取值。因此实现采用“画像方面亲和度”：先把画像标签扩展为 Amazon 商品描述中常见的同类表达，再用整个商品目录的逆流行度为这些方面加权。购买频率、历史平均评分和评分风格在当前公开数据中区分度不足，暂不进入线上排序。

这一分析只用公开测试集验证字段是否有信息，用 Amazon 商品目录计算通用统计；运行时的 Agent 不读取公开测试标签或目标商品，避免把答案泄漏进模型。

## 公开数据观察

公开集共有 200 个会话，全部属于 clothing 类别。`purchase_frequency` 的 200 个值全部为 `3-4 prior purchases`，没有方差，无法区分用户。历史平均评分与目标商品平均评分的 Pearson 相关系数约为 0.182，评分风格对应的目标商品均分也只在 4.282 到 4.413 之间变化。这样的弱相关性容易把公开集噪声固化到代码中，因此本版不使用这三个字段。

画像方面与目标商品文本的联系更明显。下表的“目标覆盖率”表示带有该画像标签的会话中，目标商品是否出现对应方面的证据；“目录覆盖率”来自全部 50,000 个 Amazon 商品；提升倍数用于判断该方面在目标商品中是否比普通商品更常见。

| 画像方面 | 会话数 | 目标覆盖率 | 目录覆盖率 | 提升倍数 |
| --- | ---: | ---: | ---: | ---: |
| fit | 163 | 85.28% | 56.60% | 1.51× |
| material | 154 | 86.36% | 67.32% | 1.28× |
| comfort | 144 | 82.64% | 47.25% | 1.75× |
| style | 101 | 85.15% | 59.74% | 1.43× |
| durability | 47 | 31.91% | 16.05% | 1.99× |

这些统计可通过 `python -m scripts.analyze_profile_signal` 复现；商品目录统计可通过 `python -m scripts.build_profile_affinity_stats` 重新生成。

## 算法如何进入排序

对画像中的每个方面 `a`，先在商品标题、类目、特征、详情、店铺和描述组成的检索文本中寻找方面证据。例如 `durability` 可以由 `durable`、`rugged`、`reinforced` 或 `heavy duty` 表达，避免旧逻辑只能匹配字面上的 `durability`。

方面权重由全部目录中的文档频率计算：

```text
w(a) = log((N + 1) / (df(a) + 1))
profile_score(p, u) = Σ w(a) · match(a, p) / Σ w(a)
```

其中 `N` 是目录商品数，`df(a)` 是提到该方面的商品数。越少见的方面区分能力越强，因此获得更高权重；常见的 material 不会压过更具体的 weather 或 durability。画像分数只参与候选集的精排，不作为硬过滤条件，也不会覆盖用户在当前会话明确提出的要求。随着对话约束增加，已有的动态约束权重仍会优先保证当前意图。

目录统计被保存为一个很小的随包文件，50,000 商品对应的计算在离线完成，Agent 启动时加载耗时约 0.0004 秒。若换用商品数量不同的目录，代码会自动重新统计，保持可移植性。

## 同版本消融结果

基线和实验均基于 `dev` 提交 `3b3cfe5`，唯一差别是 `profile_affinity_enabled` 开关。公开集结果如下：

| 指标 | 原画像字面匹配 | 画像方面亲和度 | 变化 |
| --- | ---: | ---: | ---: |
| Hit Rate@10 | 0.995 | 0.995 | 0.000 |
| MRR | 0.743752 | 0.747373 | +0.003621 |
| MTTC | 3.650 | 3.645 | -0.005 |
| Efficiency | 0.7350 | 0.7355 | +0.0005 |
| 推荐 Technical Score | 0.867626 | 0.868812 | +0.001186 |

改动影响了 43 个会话的最终名次，其中 22 个改善、21 个退化；首次命中轮次有 4 个改善、4 个退化。总体提升真实但较小，应把它视为一个有依据的长期偏好弱信号，而不是替代对话约束或语义排序的主信号。
